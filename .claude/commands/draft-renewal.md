---
description: Draft the licence renewal letter to a berth holder whose licence ends soon: the berth, the new term and fee, the papers needed, and how to accept.
---

1. Run `npm run marina -- renewals --json` and `npm run marina -- customer <holder> --json`.
2. Write `drafts/renewal-<berth>-<holder>.md`: the berth and boat, the current term's end date, the new term and the fee (the berth's list fee unless the operator says otherwise), the papers the licence asks for (current insurance with at least the minimum liability cover, an electrical check if on shore power), and how to accept.
3. If they owe money or their papers have lapsed, say so plainly in the letter as a condition of renewal. Never invent a discount.
4. Never send it. A person reads it and sends it.
