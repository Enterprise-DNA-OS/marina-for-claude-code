---
description: Render the read-only dashboards as HTML pages: the week, papers and rules, and money.
---

`npm run view` renders all three into `views/`; `npm run view -- week` renders one.

- **week**: free spaces, visitors in, haul-outs in the next 7 days, the hardstand, licences ending in 30 days.
- **papers**: insurance, electrical checks, liveaboards, unsigned licences and lift certificates.
- **money**: who owes what, drafts waiting to be issued, the fee roll by pier.

Open the file in a browser. To add a page, use /new-view.
