---
description: Draft the berth offer letter to the next person on the waiting list: the berth, its size and fee, the papers needed, and the date to accept by.
---

1. Run `npm run marina -- match --json`, `npm run marina -- berth <code> --json` and `npm run marina -- customer <name> --json`.
2. Write `drafts/offer-<berth>-<name>.md`: the berth, its length, beam and power, the annual fee before GST, the papers to send (insurance with the minimum liability cover, an electrical check if they will plug in), how long they have been waiting, and a date to accept by (14 days unless the operator says otherwise).
3. Never send it. When they accept, enter the licence (/licence).
