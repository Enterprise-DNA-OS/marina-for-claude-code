description: Occupancy and the yearly fee roll by pier, with the fee per metre, to see which piers earn and which sit empty.
---

1. Run `npm run marina -- occupancy`.
2. Present by pier: spaces, taken, free, the fee roll a year and the fee per metre of berth.
3. Pair it with the waiting list (`npm run marina -- waitlist`): a pier with free berths and a waiting list that does not fit them is a pricing or a sizing question, not a marketing one. Say which.
